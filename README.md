# 15 퍼즐

빈칸 옆 숫자를 움직여 1부터 15까지 맞추는 한국어 퍼즐입니다. 풀 수 있는 판만 섞으며 인접 이동·되돌리기·시간과 이 브라우저의 개인 최고 기록을 제공합니다. 계정·상위 host·게임 SDK·네트워크 API 없이 동작합니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. 로컬 검증 환경은 Node.js 22.23.4와 npm 11.19.0입니다.

```sh
npm ci --ignore-scripts
npm run check
npm run preview
```

표시된 loopback 주소를 엽니다. `dist/`는 정적 호스팅할 수 있습니다. 파일을 처음 받아온 뒤 퍼즐 계산은 브라우저에서 수행하며 서비스 worker나 offline 설치 기능은 제공하지 않습니다.

## 플레이

빈칸 옆 숫자를 누르거나 보드에 focus를 둔 뒤 화살표 방향의 숫자를 빈칸으로 옮깁니다. 모바일에서는 같은 숫자 버튼을 누릅니다. 되돌리기는 최근 20회까지이며 새 퍼즐은 이동·시간·되돌리기를 초기화합니다.

시간은 첫 이동부터 측정하고 완성하면 멈춥니다. 최고 기록은 이동 횟수, 같은 횟수에서는 시간 순으로 비교합니다. 기록은 이 브라우저의 개인 기록이며 서버 순위·포인트·결제·추첨 기능은 없습니다.

## 기록과 복구

localStorage의 `sliding-15-puzzle-best-v1` 한 key를 사용합니다. 손상·미지원 기록은 자동 덮어쓰거나 삭제하지 않고 안내합니다. 직접 최고 기록 지우기를 확인하면 읽었던 같은 원문만 지웁니다. 다른 화면에서 바뀐 기록과 다른 key는 보존합니다. 접근 거부나 저장 용량 문제에서도 게임과 현재 화면의 결과는 계속 사용할 수 있습니다.
